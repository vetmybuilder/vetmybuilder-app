Pick guide

  • A · Centred 2-col — closest port of mobile, lowest design risk. Same chrome rules as the rest of the new brand.
  • B · Sidebar + main — productivity-app feel. Best when filtering is heavy use.
  • C · Toolbar + dense — power-user dense view. Filters always visible. Most info on screen.
  • D · Hero header + magazine — most editorial, mirrors the homepage hero language. Lead card is bigger; rest is compact. Most distinctive but most layout work.

My pick: A if you want it shipped fast and brand-coherent. B if filtering really matters. D if you want it to feel like a flagship.
