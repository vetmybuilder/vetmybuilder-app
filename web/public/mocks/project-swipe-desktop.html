Pick guide

  • A · Centred card — closest port of mobile. Card stack visual + click action buttons + keyboard shortcuts. Lowest design risk, fastest to ship.
  • B · Deck + project context — left rail keeps the project details visible while you swipe. Reduces context switching.
  • C · Featured + queue rail — top card with action buttons and a "next up" horizontal rail underneath. Most transparent about the queue.
  • D · Featured + grid — drops the deck metaphor entirely. Top match featured, others in a 3-col grid. Best for scanning many at once. Loses the curation feel.

My pick: B if context-switching is the pain (homeowners forgetting what they posted while picking). A if you want it shipped fast and consistent with mobile. D if homeowners actually want to compare side-by-side rather than make a binary choice on each.
