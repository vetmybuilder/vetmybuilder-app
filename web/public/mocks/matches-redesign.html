What I'd change regardless of which you pick

  • Drop the "Your matches" hero. Title in the top bar is enough. Hero ate ~120px and didn't tell the user anything they didn't know.
  • Page name → "Messages" (or "Inbox" but you just retired that word). Reflects what the page actually is now: a list of conversations.
  • Show the last message preview + timestamp on every row. The current "Matched on area + trade" rationale is interesting once but burns space on every row.
  • Unread dot next to the timestamp on rows with unread messages. Currently nothing tells you what's new.
  • Tap-anywhere-on-row opens the chat. Drop the separate "Chat →" button - it's redundant.
  • Single small badge per row indicates relationship: ⚡ paid · ♥ matched · ★ recommended · ⏳ waiting. Same vocabulary across tabs and sections.

My pick: Option A

Most familiar pattern (every messaging app on Earth uses it). One scroll, everything visible, filter pills give you the slice you want. Paid pitches get an amber pill in the filter row + an amber pill on the row itself - hard to miss without dominating the layout. Mutual matches and recommended sit in the same list because they're functionally the same (you can chat with both right now).
