What changes vs the current page

  • Stepper: red 1/2/3 circles → emerald progress bar with "Step N of 3" caption (same primitive the redesigned register uses, just total=3).
  • Top bar: VetMyBuilder logo + red "Trade" pill → emerald-tinted WizardTopBar with back + close + "Trade sign-up" title (matches redesigned register exactly).
  • Pink/red background tint → plain white. Inputs sit in soft slate-50 cards.
  • Step 4 (account password) is skipped - Google handles auth, no password to set.
  • Email comes from Google and is shown read-only on Step 1 (that's already wired in complete.tsx).
  • Step 1 / 2 / 3 components reused as-is from web/components/vendor-register/. No content rewrite needed - they already look like this on /tradesman/register-tradesmen.

What stays

  • Field validation + required-marker logic per step.
  • Service-area autocomplete + chip removal.
  • Photo uploader (FileGridUploader emerald), profile picture selection.
  • Insurance / cert uploader with file list + remove.
  • Discount / warranty fields and value validation.
  • Terms checkbox gating Finish.
  • The PUT /api/tradesmen/me on Finish (no auth account creation - Google already did it).
  • Email read from auth.user.email; not editable.

Implementation is mostly mechanical: import WizardTopBar, WizardProgressBar tone="emerald", and WizardNavBar in web/pages/tradesman/signup/complete.tsx and wrap the existing Step 1/2/3 the same way register-tradesmen.tsx does. All field state, validation, submit handlers stay.
