What's warmer this round

  • Cream + peach + amber instead of plain white. Warm light, lived-in feel - what your existing /how-it-works strip already uses (bg-[#faf0e6]).
  • Caveat handwritten accent on the slogan word ("personal", "Meet your match", "made personal", "trust"). Same font you already use elsewhere on the homepage.
  • Sora display font on big headings - matches your existing hero.
  • Soft gradient blobs behind hero copy add depth without taking over.
  • Multiple section colours per scroll (cream → white → sand → dark → cream). Way less monotone than v1.
  • Steps coloured by step in Option A: amber / violet / emerald, so each feels like a different beat in the journey.

Picks

A (warm cream + indigo) - my pick. Most balanced, warmest, still clean. B (bold colour blocks) - if you want stronger brand identity / more attitude. C (photo-led) - if you want a hero photo above the fold to humanise the brand.
