/projects/[id] - Share + empty state

Right now the empty state is a tiny grey message in a white card. It should be the hero moment for sharing the job - that's the homeowner's only lever to grow their shortlist. Four directions for share placement and how the empty state should feel.

Option A · Action bar + share-CTA hero

"Share lives in the page header. Empty state becomes the share moment."

Persistent action bar at the top of the page (Back, project title, Share + More). When there are no matches yet, the swipe-deck slot is replaced by a Share to grow your shortlist hero card with one-tap channel buttons. Headline still reads Pick your tradesperson, but the empty state owns the page.

Option B · Full-bleed empty state takeover

"When empty, the page is one big share invitation."

If the shortlist is empty, ditch the swipe-deck framing entirely. Show a calm, copy-led hero - "Your community knows the best tradespeople" - with the share CTA front and centre. Once a match arrives, the page transitions back into the swipe deck. No header chrome competing for attention.

Option C · Side-rail with project + share

"Persistent project context. Share lives in the rail, always reachable."

Two-column layout. Left rail shows the project summary (title, budget, location, status) with a permanent Invite community share card underneath. Main canvas shows the shortlist - swipe deck when filled, friendly empty state when not. Same layout regardless of state, so the homeowner always knows where they are and how to grow the list.

Notes

  • Option A is the smallest delta - it keeps the existing layout, just adds a Share pill in a top action bar and gives the empty state a real CTA.
  • Option B treats the empty state as a distinct page state - homeowners with no matches yet get a calm, share-led canvas, and only see the swipe deck once it's earned.
  • Option C introduces a permanent left rail with project context and a persistent share card. Best if we expect homeowners to come back to the page repeatedly while the list grows.
  • Option D reframes the page as a 3-step journey - share is step 1, picking is step 2. Adds live counters so the page feels active even when waiting.
