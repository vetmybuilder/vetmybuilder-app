What this is

The shaded blocks marked FileGridUploader above are the actual existing component from web/components/fileUpload/FileGridUploader.tsx, dropped into the compose page with no UI changes - just different props (maxFiles=6, maxSizeMB=10, plus tone). Same dashed dropzone or "+ Upload" card. Same 3-column preview grid. Same X-to-remove affordance. Same Acceptable-Use consent checkbox.

Wiring

On submit, the photos go in the same POST as the message. /api/projects/:id/inbox-message gets extended to accept multipart with up to 6 image attachments. The page disables Send until the consent checkbox is ticked when there's at least one photo (the component already emits this via onConsentChange).

Pick one

  • Slate - same look as CloseProjectModal + the homeowner recommend flow. Reads as "neutral form field".
  • Emerald - same look as the tradesman signup docs uploader. Cleaner card, more on-brand for the tradesman side. My pick.

I'll also still fix the broken quick-prompt chips (today they leak {firstName} placeholders) and add the "Phone stays hidden" reassurance line - those changes are independent of which tone we pick.
